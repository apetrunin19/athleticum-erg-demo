# Атлетикум — демо сессии на станке

Браузерное демо кабинета тренера и кабинета атлета.

- Тренер собирает отрезки (%FTP), задаёт коридор шкалы 1–10 и назначает сессию.
- Атлет едет плеер: симулятор или живой станок по Bluetooth FTMS (Chrome / Edge).
- Шкала 1–10 двигает целевые ватты внутри коридора, число повторов не меняет.
- После заезда — карточка план vs факт по отрезкам.

Это демо, не прод. Нет аккаунтов, камеры, Strava и бэкенда. Сессия живёт в `localStorage` этого браузера.

## Открыть локально

```bash
python3 -m http.server 8080
```

http://localhost:8080

На телефоне в **приложении** станок будет. В этом веб-демо Safari / браузер на iPhone живой станок не возьмут — только симулятор. Живой FTMS: Chrome на компьютере, HTTPS или localhost.
